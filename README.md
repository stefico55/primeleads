# PrimeLeads

Application de prospection CEE (certificats d'économies d'énergie) — propriété de Visionair Studio.
Client pilote : Paclim (30 bâtiments à Corbas).

- `index.html` : application complète (HTML/JS, sans build)
- `vercel.json` : en-têtes de déploiement (noindex)

Chaque push sur `main` redéploie automatiquement sur Vercel.
